# 🏨 نظام إدارة الفنادق والحجوزات - Hotel Management System

![C++](https://img.shields.io/badge/C%2B%2B-00599C?style=for-the-badge&logo=cplusplus&logoColor=white)
![GUI](https://img.shields.io/badge/GUI-Windows_Forms-blue?style=for-the-badge)

برنامج مكتبي بواجهات تفاعلية مخصص لإدارة المنشآت الفندقية، حجز الغرف، خدمات النزلاء، وإصدار الفواتير.

---

### ✨ المميزات الرئيسية (Key Features)
1. **لوحة متابعة الغرف:** عرض الغرف المتاحة والمحجوزة وقيد الصيانة في الوقت الفعلي.
2. **إجراءات التسكين والمغادرة (Check-In / Check-Out):** تسجيل بيانات النزلاء وتحديد مدة الإقامة وحساب التكلفة الإجمالية.
3. **الخدمات الإضافية والفواتير:** إضافة خدمات الطعام والمغسلة إلى فاتورة الغرفة وطباعة الحساب النهائي.
